Cosmetic mod · Косметический мод

English · Русский

Make a hat or outfit

  1. Open Tools → Atlas: Mod Wizard → Cosmetics & UI → Mod cosmetic. Name your mod and click Create Mod → Open Generated Assets. The wizard creates a cosmetic Blueprint and definition and adds the Add Mod Cosmetics action.
  2. Import your mesh and materials into the mod folder. Open CosmeticExample/BP_ExampleCosmetic and replace the mesh on ExampleMarker under WorldView. Adjust its transform to fit the character and leave collision disabled. Compile and save.
  3. Open DA_ExampleCosmetic and set the display name. Use AccountEconomy.Equipment.Slot.Head for the Head tab or AccountEconomy.Equipment.Slot.Body for Body.
  4. In Release → Cook & Publish, select your installed game under Packaged Game, then Cook Mod → Install Test Copy → Launch Game. Enable the mod and select the cosmetic in the matching wardrobe tab.

Cosmetics use the Cosmetic Definition and the Game Feature action. Item Definitions, crafting recipes and the Items & crafting template are optional for other kinds of mods. Check Package and install for release steps.

Как сделать головной убор или одежду

  1. Выбери Tools → Atlas: Mod Wizard → Cosmetics & UI → Mod cosmetic. Назови мод и нажми Create Mod → Open Generated Assets. Шаблон создаст Blueprint и описание косметики и подключит действие Add Mod Cosmetics.
  2. Импортируй меш и материалы в папку мода. В CosmeticExample/BP_ExampleCosmetic замени меш компонента ExampleMarker под WorldView. Подгони положение и масштаб, оставь коллизию выключенной. Нажми Compile и Save.
  3. В DA_ExampleCosmetic задай название и слот. AccountEconomy.Equipment.Slot.Head — голова, AccountEconomy.Equipment.Slot.Body — тело.
  4. В Release → Cook & Publish укажи установленную игру в Packaged Game. Нажми Cook Mod → Install Test Copy → Launch Game. Включи мод и выбери косметику в нужной вкладке гардероба.

Для косметики достаточно Cosmetic Definition и действия Game Feature. Инвентарный предмет и рецепт крафта создавать не нужно.
