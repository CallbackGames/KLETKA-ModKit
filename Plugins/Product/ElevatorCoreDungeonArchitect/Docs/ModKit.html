Dungeon Architect floors

The ModKit includes KLETKA's adapter. Dungeon Architect itself is installed separately.

  1. Install Dungeon Architect 3.6.0 for Unreal 5.8, matching the game build.
  2. Enable Dungeon Architect and KLETKA Dungeon Architect Adapter in the Plugins window. Restart the editor.
  3. In Mod Wizard, choose Floors & biomes → Dungeon Architect floor. An unavailable option explains which plugin is missing or disabled.
  4. Author your own Snap Map room maps, connections, module database and flow graph with DA's tools.
  5. Open the generated DA_Floor. Under Generation → Dungeon Architect, set the one-player database and graphs. Untouched multiplayer rows inherit the closest configured lower count. The example map contains one Snap Map dungeon tagged KletkaModDungeon.
  6. Validate and cook before testing in the target game. Check generation, cancellation, multiplayer late join and save/restore. Empty databases or flow lists are incomplete authoring, not playable examples.

Distribution

Keep both adapter and DungeonArchitect plugin dependencies in the generated mod. Upload your own cooked content; do not copy either plugin into the mod. The default ModKit opens without DA because this adapter is disabled there. Enabling the adapter requires DA.

Supported contract

LeDungeonArchitectFloorGenerationConfig supplies Snap Map settings. LeDungeonArchitectFloorGenerationBackend executes the existing provider-neutral floor contract. Game and ModKit use the same implementation. Native consumers of these optional headers also require the DA SDK. Internal game modules are not part of this API.
