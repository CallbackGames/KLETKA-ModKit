Gastronom mannequins

Add kletka.dlc.gastronom to the mod manifest's package.dependencies. Use your mod's own assets. The player who hosts needs access to Gastronom. A guest joining that host needs the compatible content files.

For a mod that also uses another author's mod, the dependency list could read "dependencies": ["kletka.dlc.gastronom", "author.required_mod"]. Replace the second ID with the required mod's actual content ID.

Add a display appearance

  1. Import a skeletal mesh with bones for the parts you want to detach. In the Content Browser open the Atlas menu and choose Create Limb Profile. Select your skeletal mesh, configure its joints and bake its fragments. Save the profile inside your Game Feature plugin.
  2. Open your Game Feature Data and add Add Loot Contributions. In Contributions add one row. Set Target Pool Id to Gastronom.Mannequin.Appearance, Entry Id to a unique stable name such as MyMod.Porcelain, Operation to Append, and Weight to 1. Leave the target owner and tags empty.
  3. Choose Atlas Asset Payload as the payload struct. Set its Asset to the baked profile. Leave the action's pool declaration fields empty. Gastronom declares the pool and its type.

With only the male, female and new appearances at weight 1, each has a one-in-three chance on a display. Loading the level generates displays again from its procedural seed and the stable room and placement identities. The same inputs and active pool reproduce the same appearance. Changing the active mods or their weights can change the result. This pool chooses the appearance independently of the floor's chance to place a concealed enemy.

Add a concealed enemy

  1. Choose a replicated enemy Blueprint from your mod. It can use its own mesh, movement and abilities.
  2. On your Game Feature Data add Add Actor Placements. Add a rule with operation Weighted Variant and a tag query matching World.Actor.Slot.Mannequin.Enemy. Choose your enemy Blueprint and a positive weight.

To give the enemy the appearance of the display it replaced, implement the optional Le Mannequin Enemy interface. Its On Mannequin Placed event runs on the server and supplies the display point, skeletal mesh, limb profile and Placement Seed. Use that seed for a repeatable pose.

The floor first decides whether a display may conceal an enemy. The default chance is 15%, with at most four selections across the floor. A contributed enemy competes for that selection. The level regenerates this selection from the same procedural seed, room identity and placement identity on reload. The contributed weight controls which enemy appears within the floor allowance. Neither pool writes mannequin choices to a save.
