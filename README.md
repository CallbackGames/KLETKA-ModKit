# KLETKA ModKit

**[Download the project ZIP](https://github.com/CallbackGames/KLETKA-ModKit/archive/refs/heads/main.zip)** · [Русская инструкция](#русская-инструкция)

1. Install **Unreal Engine 5.8** on Windows.
2. Choose **Code → Download ZIP** above and extract it into a new folder. You can also clone the repository.
3. Open `KLETKA_ModKit.uproject`. Start with `START_HERE.html`.

Create your mod in `Plugins/GameFeatures/<YourModName>`. To update, download a fresh copy and move your own mod folders over.

This project is the standalone **BlueprintBinary preview**. Cook mods against a base that matches your game build. For the current Steam `default` and `beta-test` builds, wait for a matching ModKit. [Preview notes](https://github.com/CallbackGames/KLETKA-ModKit/releases/tag/preview-2026-11-23)

**C++ editor tools** use the optional [NativeSdk archive](https://github.com/CallbackGames/KLETKA-ModKit/releases/download/preview-2026-11-23/KLETKA-ModKit-NativeSdk-Win64.zip). The editor and third-party materials are subject to their applicable licences. See the included `Legal` folder.

## Русская инструкция

1. Установите **Unreal Engine 5.8** на Windows.
2. Нажмите **Code → Download ZIP** и распакуйте архив в новую папку. Можно также клонировать репозиторий.
3. Откройте `KLETKA_ModKit.uproject`. Начните с `START_HERE.html`.

Создавайте свои моды в `Plugins/GameFeatures/<ИмяМода>`. Чтобы обновиться, скачайте свежую копию и перенесите в неё папки своих модов.

В репозитории лежит предварительная версия **BlueprintBinary**. Для упаковки мода нужна cook-база вашей сборки игры. Для текущих сборок Steam на `default` и `beta-test` дождитесь совместимого выпуска. [Описание выпуска](https://github.com/CallbackGames/KLETKA-ModKit/releases/tag/preview-2026-11-23)

Разработчикам **C++-инструментов для редактора** доступен [архив NativeSdk](https://github.com/CallbackGames/KLETKA-ModKit/releases/download/preview-2026-11-23/KLETKA-ModKit-NativeSdk-Win64.zip).
